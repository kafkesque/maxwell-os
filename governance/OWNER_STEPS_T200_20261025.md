## STEP 3 — Install 0.7.3.dev2, then IMMEDIATELY re-run step 2

**The update route is the app's OWN updater — no download URL, no vendor hunt.** MEASURED 2026-10-25 by reading
`~/Library/Application Support/oMLX/update-prefs.json`:

```
{"channel":"dev","deferredPromptVersion":"0.7.3.dev2","autoNotify":true,"autoCheck":true}
```

`deferredPromptVersion` **names 0.7.3.dev2**: the app has already offered this exact build on the `dev` channel and the
prompt was deferred. So the build is reachable in one click, and step 1's return point is what makes that safe.

1. Open **oMLX** (the app, not the CLI — `omlx --version` launches the GUI and hangs; read the version instead with
   `/usr/bin/plutil -extract CFBundleShortVersionString raw /Applications/oMLX.app/Contents/Info.plist`).
2. Menu: **oMLX → Check for Updates**. Install **0.7.3.dev2** when it is offered.
3. If no prompt appears, the deferred version is being suppressed: set `"deferredPromptVersion": null` in
   `update-prefs.json`, quit and reopen the app, then Check for Updates again.

```
/usr/bin/plutil -extract CFBundleShortVersionString raw /Applications/oMLX.app/Contents/Info.plist
```
